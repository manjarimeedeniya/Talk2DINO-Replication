# Talk2DINO Replication

This project explores **CLIP** and **DINOv2** as a foundation for understanding and implementing **Talk2DINO: Bridging Self-Supervised Vision Backbones with Language for Open-Vocabulary Segmentation**.

## Objective

The main objective is to understand how language representations from CLIP can be connected with visual representations from DINOv2 and used for open-vocabulary image segmentation.

The project will be carried out in several stages:

1. Explore CLIP and its image-text feature representations.
2. Explore DINOv2 and its visual feature representations.
3. Compare and understand the roles of CLIP and DINOv2.
4. Study and implement the original Talk2DINO codebase.
5. Run the original pretrained model on test images.
6. Propose and implement a modification or use case.
7. Compare the original and modified approaches.
